# Атлас упражнений

Учебное Flutter-приложение для Android и Windows. Ищите упражнения по английскому названию, группе мышц и сложности, открывайте карточки с техникой выполнения и сохраняйте их в избранное. Сохранённые карточки доступны без сети.

## Запуск

1. Получите бесплатный ключ в личном кабинете [API Ninjas](https://api-ninjas.com/).
2. В папке проекта выполните:

       flutter pub get
       flutter run -d windows

   Для Android замените windows на идентификатор подключённого устройства или эмулятора (список: flutter devices). Если Flutter на Windows попросит разрешить создание символических ссылок для плагинов, включите «Режим разработчика» в параметрах Windows.
3. Нажмите значок ключа в приложении, вставьте ключ, затем найдите, например, push up. Ключ из окна настроек хранится только до закрытия приложения. Для локальной отладки также можно передать его при запуске:

       flutter run -d windows --dart-define=API_NINJAS_KEY=ВАШ_КЛЮЧ

   Не публикуйте сборку, в которую передан личный ключ.

## Сетевой слой

- Dio вызывает [Exercises API](https://api-ninjas.com/api/exercises). Бесплатный запрос возвращает до пяти результатов; сузьте фильтры, если нужного упражнения нет в выдаче.
- ApiKeyInterceptor автоматически добавляет X-Api-Key к запросам на HTTPS-адрес API Ninjas. PrettyDioLogger пишет запросы в режиме отладки без заголовков и тел ответов.
- GetIt регистрирует настройки ключа, Dio, репозиторий и хранилище избранного. Избранное сохраняется через SharedPreferences.
- Интерфейс показывает загрузку, пустой ответ и ошибки подключения, авторизации и лимита запросов.

Проверки: flutter analyze и flutter test. Тесты используют подмену HTTP-адаптера и не требуют ключа.
