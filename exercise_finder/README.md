# Атлас упражнений

Учебное Flutter-приложение с поиском по названию, группе мышц и сложности. Карточки с техникой выполнения загружаются из GymFit API. Избранное сохраняет идентификатор и название упражнения, а для открытия полной карточки нужно подключение к сети.

## Запуск в браузере

Из корня репозитория выполните:

    cd exercise_finder
    flutter pub get
    flutter build web
    dart run tool/serve_web.dart

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080) в Chrome или Edge. Держите терминал с сервером открытым. Сервер доступен на этом компьютере и передаёт запросы из веб-версии в GymFit, поскольку GymFit не разрешает прямые запросы из браузера с localhost.

Если на Windows уже загружены пакеты, а Flutter при запуске жалуется на символические ссылки, используйте flutter build web --no-pub и dart tool/serve_web.dart. Для первого flutter pub get может потребоваться режим разработчика Windows.

## Ключ GymFit

Зарегистрируйтесь на [GymFit API](https://www.gymfit-api.com/signup) и скопируйте ключ из личного кабинета. В приложении нажмите значок ключа, вставьте ключ и нажмите «Применить». Попробуйте поиск squat или push-up. Введённый ключ хранится в памяти до закрытия приложения или обновления вкладки.

## Android и Windows

Подключите Android-устройство и выберите его через flutter run -d ID_УСТРОЙСТВА (список показывает flutter devices). Для Windows используйте flutter run -d windows.

## Сетевой слой

Dio вызывает [GymFit API v2](https://api.gymfit-api.com/). ApiKeyInterceptor добавляет X-API-Key к запросам GymFit или локального сервера веб-версии. PrettyDioLogger выводит запросы в режиме отладки без заголовков с ключом. GetIt регистрирует настройки ключа, Dio, репозиторий и избранное.

Проверки: flutter analyze и flutter test. Тесты используют подмену HTTP-адаптера и не требуют ключа.
